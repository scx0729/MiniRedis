# MiniRedis17 支持的命令

## 连接命令

### PING
- **参数数量**：-1（可变）
- **返回**：PONG，或回显参数
- **示例**：
  - `PING` → `+PONG\r\n`
  - `PING hello` → `$5\r\nhello\r\n`

### ECHO message
- **参数数量**：2
- **返回**：批量字符串（消息内容）
- **示例**：`ECHO hello` → `$5\r\nhello\r\n`

### QUIT
- **参数数量**：1
- **返回**：+OK
- **效果**：发送响应后关闭连接

## 通用键命令

### DEL key [key ...]
- **参数数量**：-2
- **返回**：整数（被删除的键数量）
- **说明**：忽略不存在的键

### EXISTS key [key ...]
- **参数数量**：-2
- **返回**：整数（存在的键数量）

### TYPE key
- **参数数量**：2
- **返回**：简单字符串（none/string/list/hash）

## 字符串命令

### SET key value [EX seconds] [PX milliseconds] [NX|XX]
- **参数数量**：-3
- **返回**：OK，如果 NX/XX 条件不满足则返回 nil
- **选项**：
  - `EX seconds` - 以秒为单位设置过期时间
  - `PX milliseconds` - 以毫秒为单位设置过期时间
  - `NX` - 仅在键不存在时设置
  - `XX` - 仅在键存在时设置
- **行为**：覆盖已有的值。除非指定了新的 TTL，否则清除已有的 TTL。
- **冲突规则**：EX/PX 以最后一个为准。NX 和 XX 互斥，以最后一个为准。

### GET key
- **参数数量**：2
- **返回**：批量字符串或 nil
- **错误**：如果键持有非字符串类型，返回 WRONGTYPE

### MSET key value [key value ...]
- **参数数量**：-3（参数个数为奇数时报错）
- **返回**：+OK
- **说明**：原子性地设置多个键

### MGET key [key ...]
- **参数数量**：-2
- **返回**：批量字符串数组（不存在的键返回 nil）

### APPEND key value
- **参数数量**：3
- **返回**：整数（追加后的字符串长度）
- **说明**：键不存在时创建

### STRLEN key
- **参数数量**：2
- **返回**：整数（字符串长度），键不存在时返回 0
- **错误**：如果键持有非字符串类型，返回 WRONGTYPE

### INCR key
- **参数数量**：2
- **返回**：整数（递增后的值）
- **说明**：键不存在时从 0 开始。值不是整数时返回错误。检查 int64_t 溢出。

### DECR key
- **参数数量**：2
- **返回**：整数（递减后的值）
- **说明**：规则与 INCR 相同

## 列表命令

### LPUSH key element [element ...]
- **参数数量**：-3
- **返回**：整数（压入后的列表长度）

### RPUSH key element [element ...]
- **参数数量**：-3
- **返回**：整数（压入后的列表长度）

### LPOP key
- **参数数量**：2
- **返回**：批量字符串或 nil
- **说明**：列表变空时删除键

### RPOP key
- **参数数量**：2
- **返回**：批量字符串或 nil
- **说明**：列表变空时删除键

### LLEN key
- **参数数量**：2
- **返回**：整数（列表长度），键不存在时返回 0
- **错误**：如果键持有非列表类型，返回 WRONGTYPE

### LRANGE key start stop
- **参数数量**：4
- **返回**：批量字符串数组
- **说明**：
  - 支持负索引（-1 = 最后一个元素）
  - 越界索引会被钳制
  - 键不存在时返回空数组

## 哈希命令

### HSET key field value [field value ...]
- **参数数量**：-4
- **返回**：整数（新增字段的数量，不包括更新的字段）

### HGET key field
- **参数数量**：3
- **返回**：批量字符串或 nil

### HDEL key field [field ...]
- **参数数量**：-3
- **返回**：整数（删除的字段数量）

### HLEN key
- **参数数量**：2
- **返回**：整数（字段数量），键不存在时返回 0
- **错误**：如果键持有非哈希类型，返回 WRONGTYPE

### HGETALL key
- **参数数量**：2
- **返回**：批量字符串数组 [field1, value1, field2, value2, ...]
- **说明**：按排序顺序返回字段（用于测试的确定性）

## TTL 命令

### EXPIRE key seconds
- **参数数量**：3
- **返回**：1 表示设置成功，0 表示键不存在

### PEXPIRE key milliseconds
- **参数数量**：3
- **返回**：1 表示设置成功，0 表示键不存在

### TTL key
- **参数数量**：2
- **返回**：整数（TTL 秒数），-1 表示无过期时间，-2 表示键不存在
- **说明**：向下取整

### PTTL key
- **参数数量**：2
- **返回**：整数（TTL 毫秒数），-1 表示无过期时间，-2 表示键不存在

### PERSIST key
- **参数数量**：2
- **返回**：1 表示过期时间已移除，0 表示键不存在或无过期时间

## TTL 语义

- `SET key value` 清除已有的 TTL
- `SET key value EX n` 设置新的 TTL
- `INCR`、`APPEND`、`LPUSH` 等保留已有的 TTL
- `EXPIRE` 对不存在的键返回 0
- `EXPIRE` 秒数 <= 0 时立即删除键
- TTL 内部以毫秒存储
- `TTL` 返回剩余秒数的向下取整
- 过期键通过惰性删除（访问时）和主动删除（周期性扫描）清理

## 与 Redis 的差异

- HGETALL 按排序顺序返回字段（Redis 使用 dict 的未指定顺序）
- 协议错误会断开客户端连接（Redis 尝试继续处理）
- 没有 MULTI/EXEC、SUBSCRIBE 等（参见范围外功能）
- 配置语法简化（key=value，非 Redis 配置格式）
