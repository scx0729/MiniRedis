# Task 0 Rubric: 错误模型与 ByteBuffer

| 项目 | 权重 | 要求 |
|------|------|------|
| 正确性 | 55% | 通过公开测试并满足 README/API 语义。 |
| 边界情况 | 20% | 处理空输入、缺失 key、错误类型、截断输入、溢出或系统调用错误。 |
| 资源安全 | 10% | 无泄漏、无悬垂 fd/指针、无未定义行为。 |
| 代码结构 | 10% | 实现局部、清晰，不绕过接口或硬编码测试。 |
| 测试质量 | 5% | 添加或扩展有意义的单元/集成测试。 |

隐藏测试会覆盖公开测试没有完全覆盖的协议边界、错误路径和顺序依赖。
